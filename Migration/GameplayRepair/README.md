# 玩法、性能与播放器显示修复（2026-09-16）

## 范围与原文件

修改作用于本 Unity 项目的 `Assets/StreamingAssets/Emoji/scripts` 和 `Assets/EmojiBridge`。外部 `C:\Test\Emoji_Survivor` 保留为参考原作，没有覆盖。修复前 Lua 另存于本目录 `Original/scripts`。旧 `Migration/Validation` 是移植阶段的证据，本次修复证据以本目录为准；修改后的 Lua 不再与原作逐字节相同。

## 刷怪与数量压缩

原作已有对象池和 60 只上限，并非大量 Unity GameObject Instantiate/Destroy。原来超过上限的请求直接丢弃，而且普通怪可能占满位置，让精英无法出生。

现在总上限仍为 60，普通与精英最多 59，预留 1 个 Boss 位置；同一波先安排精英，再安排普通怪。限制每次刷怪循环的有效工作量，已满时不再遍历整批无效请求。

数量因子为 `min(8, max(1, 本波预计敌人数 / 59))`，预计数量计入蜂群的平均额外个体。生命和经验乘以数量因子；攻击乘以 `min(1.15, 1 + 0.08*ln(数量因子))`。它只作用于新出生敌人，不突然强化场上存活敌人，速度与 Boss 血量不受这层压缩影响。数量因子封顶意味着极端压力不会无限保留。

200 次 W140 刷怪逻辑测试约由 111.9 ms 降至 50.0 ms。此项不是完整帧率测试。矢量渲染另修复了每个描边顶点重复生成圆帽的问题，并为无需裁剪的三角形增加快速路径。满场 Game View 采样见 `performance-runtime.json`；只代表本机编辑器的短时负载。

## 伤害试调

`battle/DamageBalance.lua` 将攻击和生命成长分开。攻击系数为 `1 + 0.135*min(w,30) + 0.08*max(w-30,0)`，不再继承 W40 血量翻倍和 W50 后的血量指数项。精英基础攻击乘 0.42，冲锋怪乘 0.65；保留精英狂暴的原 1.8 倍。难度、每日和每周挑战的攻击修正继续生效。

敌方投射物命中伤害取原伤害的 55%，向下取整且至少为 1。区域技能不套这层投射物系数。同帧命中的敌方子弹和区域伤害只结算最大一次，其他命中仍列入候选统计；这修复了原先先求和、再进入玩家无敌帧判断的堆叠路径。魅惑子弹对敌伤害保持原值。

固定参考构筑：普通难度、叶子、等级=波次+1、生命提升 5 级、无图腾/遗物/符文。以下“次数”为满血到致死命中的次数（`ceil(最大生命/单次伤害)`），未计入回复与保命资源。

|---|---:|---:|---:|---:|

|40|115|17|34|7 / 4|

攻击计算不读取实际玩家生命，额外生命养成仍增加承伤能力。新的曲线也会改变前 30 波部分攻击值，这次是统一试调而非只替换 W40 一个节点。

## 死亡诊断

`battle/CombatTelemetry.lua` 保留最近 64 次受伤尝试，死亡时输出 `[CombatDeath]` JSON，并写入存档目录 `combat_death.json`。记录波次、等级、伤前/伤后/最大生命、来源、同帧命中数、基础伤害、数量/攻击压缩倍率、输入与减伤后伤害、候选伤害总和、护甲、无敌时间、守护/护盾次数、钢铁/急救/浴火符文资源。无敌或护盾拦截也会记录。

`encounters-40/80/140.json` 为 36 场固定种子、固定阵容、站桩/圆周移动各半的 30 秒短时模拟：18 次死亡，均为接触伤害；0 次满血单击死亡，0 次运行错误。移动组在该窗口存活。它不是玩家遥测，也不涵盖全部 Boss、挑战倍率或完整 W1–W140 流程。W140 场景已修正测试中清空 Boss 引发的误通关问题。

## 图腾、Emoji、黑屏

- `hp_regen` 图腾实际每秒恢复最大生命的 10%/20%/35%，原名称“掘金”和金币描述错误。现改为“生命再生 / 每秒恢复最大生命 / %/s”，保持 ID、存档和实际效果不变。
- 旧独立程序截图中 Emoji 全部显示方框，编辑器正常。现采用预生成彩色图集 `emoji-glyphs.json` + `EmojiAtlas0.png`，包含 530 个游戏使用字形及组合映射，使用普通纹理导入以保留稳定纹理引用；播放器直接按字形坐标绘制 PNG，不创建或克隆彩色 FontAsset，避免构建清理与销毁时丢失图集。编辑器参考字形资产保留在 Editor 目录。旧字体不支持的翅膀用鸽子字形替代，两个装饰星形用已有星星字形替代。
- 使用持久化 `EmojiPanelSettings.asset` 将 UI 所需着色器带入构建；对非法窗口尺寸加保护，桥接/绘制异常会显示错误提示，避免只留下空白画面。
- 用户报告的“导出程序进入后立刻黑屏”在旧诊断包中未稳定复现，旧包标题和战斗可见但有方框。因此不能将其宣称为已定位的单一根因。最终独立程序截图和日志用于核实本机当前启动与进入战斗画面。
