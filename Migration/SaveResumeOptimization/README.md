# 本轮优化：标题、暂停存档与 emoji 比例

## 完成内容

- 中文标题：Emoji幸存者；英文标题：Emoji Survivor。主界面与页脚保持一致。
- 暂停页增加“存档并退出 / Save & Exit”，保存后返回主界面，不结算、不发奖励。原“结算退出 / Settle & Exit”保留。
- 存档有效时主界面显示“继续游戏”。损坏或不完整的存档不会显示此入口；写入失败保留暂停状态并显示失败提示。
- 新版 v2 存档保存角色属性与技能、敌人及 Boss、弹幕与掉落、局内金币、技能及符文冷却、地图与地形、挑战规则、复活使用状态。共享目标引用通过图结构序列化保留。
- 继续游戏保留皮肤、礼物选择状态及技能选择状态，不会额外解锁随机地图。自动存档延后至完整更新结束，包含该波新生成的 Boss。
- 保留 v1 存档读取兼容。旧档缺失的完整战场信息无法凭空补回，仍采用旧版重建敌人的兼容路径。
- emoji 使用图集原始宽高比，在原字号范围内居中绘制。手柄图案从正方形恢复为 96:69，修复纵向拉伸；不改变碰撞数值。
- Windows 存档采用临时文件替换并回读校验。无效 JSON 与文件读写失败不会使 Lua 桥接永久停止。

- 独立 Windows Player 使用两个进程验证：第一进程存档返回主界面并退出；第二进程从磁盘继续。断言第 40 波、等级 27、生命 73、Boss 剩余生命 321、局内金币 127 均恢复。
- 自动验证通过程序调用真实游戏入口和按钮处理函数，不等同于长时间人工键鼠游玩。诊断存档位于临时 EmojiDiagnostics 目录，回归测试使用内存文件，不改动玩家正常存档。

## 边界

- 新开游戏会替换旧的局内存档；死亡或结算会删除局内存档。
- 每日挑战继续沿用保存时的规则。跨周的旧赛季存档不会向新赛季计分。
- 恢复当前状态，但不保证恢复后未来随机抽取结果与未退出时完全相同。
- 原 UrhoX 游戏文件未修改。

最终 Windows 构建成功：0 错误、1 条 Pipeline 配置警告（可选 Pipeline 未配置，Player 中禁用）。上一轮完整编译还有 3 条现有 TextCore 过时 API 警告。
